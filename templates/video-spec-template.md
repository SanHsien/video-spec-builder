# Video Spec 模板

復制下面代碼塊整段，存成項目根目錄的 `video-spec.md`。每個 `[方括號]` 是一個佔位符——把方括號連同裏面的說明文字，整個替換成你的真實內容。

填寫時要查的文檔：

- 字段約束 / 規格一致性校驗 / 交付前自檢清單 → `references/spec-rules.md`
- 分鏡表「組件」字段填什麼 ID → `references/components-catalog.md`
- 逐字稿 / 賣點怎麼拆成一鏡一鏡 → `references/scene-breakdown.md`

```
請你按照以下 script，幫我生成一條視頻。以下是這條視頻的 script 和詳細講解。


## 1. 視頻基本盤

- 標題：[視頻標題]
- 目的：[這條視頻要達成什麼——讓誰記住什麼、看完去做什麼]
- 受衆：[目標觀衆是誰——職業、痛點或關注點、在什麼場景觀看]
- 觀衆熟悉度：[觀衆已經懂的術語，以及不要預設他懂的術語]
- 平臺與時長：[在哪個平臺播放、總時長多少]
- 畫面規格：[畫面比例、幀率、是否需要無聲也能看懂]
- 輸出：[文件格式、畫質]
- 核心信息：[一句話 takeaway，短到能當大字海報標題]
- 信息密度：[整體是快節奏抓眼球、穩節奏講清楚、還是慢節奏沉浸，一句話說明]
- 語氣基調：[用什麼風格說話，給一兩個具體參考形象；以及明確不要的風格]


## 2. 敘事結構

- 敘事節拍：[把全片切成幾段——每段佔多少時間、各自的職責是什麼]
- 情緒曲線：[開頭、中段、收尾分別是什麼情緒，要有變化方向]
- 音畫關系：[BGM 是敘事性還是氛圍性；標出至少一處音畫錯位的地方]
- 同質化反例：[這條視頻在視覺、敘事、節奏上分別不要做成什麼樣]


## 3. 表達手段

- 場景類型組合：[這條視頻用哪幾種畫面手段，按出現順序列出]
- 字幕呈現：[字幕怎麼出現——整句、關鍵詞高亮、還是逐詞卡拉 OK]
- 關鍵詞強調：[要不要畫圈、高亮、手繪標記這類強調；不要就寫不需要]
- 文字動效：[要不要打字機、動態字重這類文字動畫]
- 3D：[要不要 3D；要的話用在哪、模型從哪來]
- 轉場風格：[轉場整體怎麼處理——硬切爲主還是多用花式轉場，大致比例]
- 特殊視覺：[要不要 shader 轉場、音頻反應可視化、路徑動畫這類；要就說用在哪]
- 節奏基準：[平均每個鏡頭多少秒、旁白總字數大概多少]


## 4. 視覺規範

- 視覺主題：[預設名（如 Swiss Pulse），或自定義主題寫 "design.md（項目根目錄）"]
- accent 色：[強調色，不改寫默認，改就給具體色值]
- 裝飾密度：[畫面裝飾偏多還是偏少]
- 組件取舍：[有沒有特別想用、或絕對不要用的組件；沒有就寫無]


## 5. 素材清單

### 已有素材

[逐項列出手頭已有的素材——旁白腳本、視頻片段、真人出鏡、圖片、數據、Logo、字體、3D 模型等，每項給出具體文件路徑]

### 待生成素材

[需要現場生成的素材——比如 TTS 旁白、字幕、摳像，每項寫清楚怎麼生成、產出到哪個文件]

### 待搜索素材

[需要去素材網站找的東西，每條寫清楚：去哪個平臺、搜什麼英文關鍵詞、用在哪、驗收標準是什麼。沒有就寫「無搜索素材需求」]


## 6. 分鏡表

一個鏡頭一段，從 Scene 01 起補零編號。每個鏡頭按下面的字段寫：

### Scene 01 · [起始秒]–[結束秒] · [這一鏡在敘事裏的角色]

- 類型：[主線講解鏡、輔助鏡、還是純過場轉場]
- 組件：[這一鏡用哪個組件，填 components-catalog.md 裏的真實組件 ID]
- 旁白文案：[這一鏡的完整旁白原文；沒有旁白就寫無]
- 屏顯文案：[屏幕上顯示的文字，可以和旁白不一樣；沒有就寫無]
- 期待內容：[這一鏡要傳達的具體內容——數據、概念、情緒還是動作]
- 期待效果：[觀衆看完這一鏡該產生什麼反應——震撼、理解、記住、共鳴]
- 畫面描述：[鏡頭裏有什麼、怎麼布局、是否 3D、9:16 還是 16:9 怎麼適配、關鍵視覺元素]
- 動效要點：[畫面怎麼動，用動詞描述，不寫具體毫秒和緩動參數]
- 音效描述：[有沒有音效；有就寫什麼音效、什麼時間點、音量多大；沒有寫無]
- 轉場進入：[這一鏡怎麼切入]
- 轉場離開：[這一鏡怎麼切出]
- 素材依賴：[這一鏡用到哪些具體素材]

### Scene 02 · ……

[後面每個鏡頭依此類推，字段相同]


## 7. 音頻時間軸

- 旁白：[每段旁白的起止時間、來源、音量]
- 背景音樂：[BGM 的起止時間、文件、音量、淡入淡出；旁白出現時壓低到多少]
- 音效：[每個音效的時間點、是什麼、文件、音量]


## 8. 參考與反例

- 正向參考：[一到三個具體參考作品，每個說清楚像在哪、又有哪一點要做得不一樣]
- 靜態參考：[海報、截圖這類靜態參考，說清楚參考它的哪一點]
- 反例：[明確不想做成的樣子——具體的視頻或友商，以及討厭它哪一點]


## 9. 開放問題

[還沒定下來、需要補充或需要和用戶確認的點，逐條列出；全都定了就寫「無，spec 已完整」]
```
